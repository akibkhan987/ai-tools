# Stake Ledger

A private betting tracker: deposits and withdrawals, bets, tipster-group performance, and daily / weekly / monthly profit and loss.

Everything is stored in your own browser (localStorage). Nothing is sent to any server. Use **Settings → Download backup** regularly, and **Restore from backup** to move your data to another device.

Live site: https://akibkhan987.github.io/ai-tools/
